작전 개요

전쟁기념관 실내·외 전 구역을 자유롭게 탐색하며 역사적 아카이브를 복구해야 합니다. 각 편대(반)별로 배정된 작전 테마에 맞는 전시품을 찾고 사진을 촬영하여 전송하십시오.

행동 수칙
  • 1. 완전 해독 필수: 16칸의 빙고판을 모두 채워야 작전이 완료됩니다.
  • 2. 극비 지령 (4칸): 금색 테두리는 필수 특별 미션(선생님 접선 등)입니다.
  • 3. 자유 탐색 (12칸): 배정된 테마에 맞춰 기념관 곳곳을 둘러보고 자유롭게 전시품을 촬영하세요.
  • 4. 작전 로그: 관람 후 아래 MISSION LOG에 소감을 한 줄 남기세요.

function doPost(e){
  const ss=SpreadsheetApp.openById('1nWCYrJuGPscu5LmVX7nCfmXTgaOEI9ahJmXb2v4TKSg');
  let sh=ss.getSheetByName('소감기록');
  if(!sh)sh=ss.insertSheet('소감기록');
  if(sh.getLastRow()===0)sh.appendRow(['시간','반','이름','소감']);
  const d=JSON.parse(e.postData.contents);
  sh.appendRow([new Date(),d.className,d.writer,d.text]);
  return ContentService.createTextOutput(JSON.stringify({ok:true})).setMimeType(ContentService.MimeType.JSON);
}
function doGet(){return ContentService.createTextOutput('ok');}
